# my Moyu（dsh-my-moyu）

自用上班摸鱼助手。

上班摸鱼一条龙：下班倒计时、天气、OCG 用量、六十四卦、塔罗、今日黄历、电子木鱼。两种形态，同一套配置：

- **头部胶囊**（默认）：挂在 `conversation.session.header.utilities`，对话头部右对齐那一行。
- **浮动胶囊**：挂在官方浮层 `shell.overlay`，钉在视口某一角，可拖动、可跨页面常驻；底部工具行（木鱼 / 签筒 / 塔罗）默认收起，**hover 时带动画向下展开**，详情面板不参与这个收起。

## 简单页（浮窗形态）

```
┌───────────────────────────────┐
│ ● 距下班 01:23:45      ☀ 晴 8°C │
│   ( 21 )    ( 8 )    ( 3 )    │
│    5小时     本周     本月      │
│             🪵                │
└───────────────────────────────┘
```

- **三行卡片**：第一行倒计时 + 天气，第二行三环用量（三等分整行），第三行居中的木鱼
- **280px 宽、高度自适应、14px 圆角**，已不是胶囊；整卡**鼠标手势为默认箭头、不可选中文字**
- **木鱼**：pointer 手势，点一下播一次敲击音（WebAudio 实时合成，无音频素材）+ 弹跳动画；暂不计数；点击不会冒泡去开合详情面板
- 与 320px 宽的详情页**水平居中**（按中线对齐，不是左缘对齐）
- 头部形态仍是单行小胶囊（28px 高），不显示用量环与木鱼
- 字号整体 +1 号：倒计时数字 15px、天气温度 14px、说明文字 13px
- 天气块 = 彩色图标 + 翻译后的天气码 + 摄氏度；无数据时整块（含分隔线）不出现
- 用量环 = 5 小时 / 本周 / 本月三个窗口的**已用百分比整数**，环心是数字、环下是标签；颜色按档位变（<70 蓝 / 70~89 橙 / ≥90 红）

| 状态 | 显示 |
| --- | --- |
| 工作日、上班前 | `距上班 00:47:12` |
| 工作日、班中 | `距下班 01:23:45` |
| 工作日、下班后 | `已下班` |
| 非工作日 | `休息日` |

状态点：班中=品牌色、上班前=次级文字色、下班/休息=静默色。（曾有的「快下班整颗转绿」已按需求移除）

## 详情面板（悬停胶囊）

- 与卡片**水平居中**（320px 宽 vs 卡片 280px，按中线对齐）；下方放不下自动翻到上方
- **胶囊与面板共用一套纯白底色**：白底 + 固定深色文字（`--wcd-*` 局部变量），不随宿主亮暗翻转
- **最上面是用量块**：三个大环（34px）+ 窗口名 + 重置时刻
- 头部：`☀ 杭州 晴 12.8°C 体感 10.9°C 7°C~18°C`
- **未来 24 小时**：横向滚动，**滚动条隐藏**（右侧渐隐提示还有内容）；**滚轮**和**按住鼠标拖拽**都能滑
- **首格 = 当前小时**：蓝色浅底 + 时间加粗，一眼看出哪格是「现在」
- 每格：`09:00 / 12°C / 晴 / 彩色图标`
- **未来 3 天**：今天 / 明天 / 后天三列网格，不滚动，同样带图标
- 面板内**不可选中文字**，光标统一默认箭头（不会出现框选和蓝底白字）；点击面板外或按 `Esc` 收起
- **悬停胶囊即展开**，鼠标可以移进面板；离开胶囊与面板**累计 200ms** 才收起，出现/收起都有淡入淡出
- **拖动只在浮窗顶部把手**上进行（hover 时淡入的三横灰色图标，`cursor:grab`），主面板其余区域不响应拖动；拖到 3px 以上才算拖动

图标是内联 SVG（晴=琥珀、云=灰、雨=蓝、雪=冰蓝、雷=紫），颜色写死——图标属于美术素材。

**注意**：底部胶囊与面板现在是固定浅色卡（按需求「纯白」），所以在深色主题下会是一块白卡，不再跟随主题变色。要跟随主题只需把 `.wcd-pill,.wcd-panel` 里那组 `--wcd-bg/--wcd-fg/...` 换成 `--dsw-alias-*`。

## 今日黄历（详情页最顶上）

展开详情页后最上面是一块日历页：公历日期 + 星期 + 农历、干支、值神（黄道/黑道）、宜、忌、冲煞、建除、二十八宿。

```
11月20日 周五        二〇二六年十月十二
丙午年 己亥月 戊戌日          金匮 · 黄道
冲龙 · 煞北 · 闭日 · 牛宿凶
宜  合帐 裁衣 嫁娶 安床 入殓 移柩 破土
忌  置产 造船 开光 掘井 作灶
```

- 计算在**宿主侧**完成，纯本地、不联网；每天算一次，日期变了才重写快照
- 算法层：干支日柱 + 建除十二神 + 二十八宿 + 黄黑道十二神 + 神煞叠加，最后按「以凶制吉 / 宜忌从多」汇总；规则集大成于清代《协纪辨方书》
- 宜/忌条数各家通书不同，这属于**流派差异**，不是 bug
- 库：`lunar-typescript`（MIT），**内联在 `vendor/lunar.cjs`**（450KB）。之所以不用裸包名依赖：本插件是 `link:` 安装，Node 从真实路径解析不到 profile 的 `node_modules`
- 许可与来源见 `vendor/LICENSE-lunar.txt`

## 卦象（签筒）

木鱼右侧的签筒，点一下起一卦，弹出结果卡：卦序 + 卦象名（如「水雷屯」）+ 六爻图 + 卦辞原文 + 白话总述，有动爻时并排给出**变卦**。

- **铜钱法起卦**：三枚铜钱摇六次，每爻 1/8 老阴、3/8 少阴、3/8 少阳、1/8 老阳；老阴/老阳为动爻，翻转后得到变卦，动爻在爻图上标蓝
- 一次一卦，**不入库、不记录、关掉即弃**
- **完全离线**：数据内嵌、随机源用 `crypto.getRandomValues`、无任何网络调用（测试里有守卫断言）
- **没有 384 条爻辞**：动爻只标位置（初爻、三爻…），变卦给卦名 + 卦辞原文 + **白话解读**，不逐爻断辞
- 六爻皆静时不出变卦，直接看本卦
- 弹窗点遮罩、点 ×、按 Esc 都能关；底部固定一行免责说明

### 卦辞与白话的来源

- **卦辞**：《周易》原文，公有领域
- **白话**：本次自撰的整段散文（约 110~160 字），从卦象画面讲到现实处境，不再分「事业/感情/财运/人际」四栏
- 数据取自 npm 包 `iching-divination`（**MIT**）的 `iching_simplified.json`，但该包存在系统性错误：**每一卦的卦辞/爻辞被填成了其「综卦」（上下颠倒）的内容**，只有 8 个自对称卦（乾坤坎离颐大过中孚小过）碰巧正确。本插件在构建时按位反转做了校正，并逐卦核验（测试里有屯/蒙、既济/未济等锚点断言）

## 塔罗（大阿卡那）

签筒右侧的牌背图标，点一下从 **22 张大阿卡那**里连抽 **3 张**（不重复），每张独立随机**正位 / 逆位**，按「过去 · 现在 · 未来」落位。

- 弹窗内容：三列牌阵，每列「位置名 + 牌名 + 正/逆位徽章 + 位置专属解读」，底部一段综合判断（按逆位张数 0/1/2/3 给结论）
- 点击牌背时，图标绕自身中轴旋转一整圈（180°×2，`.55s`）
- **位置专属解读共 132 段**（22 张 × 3 位置 × 正逆），本次自撰、约 40~80 字/段；另有 44 段单张牌义作为位置表缺项时的兜底
- 同样**完全离线**：数据全部内嵌、随机源 `crypto.getRandomValues`、无网络调用
- 与签筒互斥：开一个会自动关另一个；遮罩、×、Esc 都能关
- 底部共用同一行免责说明

## 木鱼音源

`assets/knock.mp3` + 内嵌到 `client.js` 的 base64 副本（两份内容必须一致），来源：

- **Temple block - Lunarlander 1969** by **Sadiquecat** — https://freesound.org/people/Sadiquecat/sounds/742279/
- 许可：**CC0 1.0（公共领域）**，可自由复制、修改、分发，无需署名（此处署名仅为溯源）
- 高质量预览版 30KB / 1.206s；运行时 `decodeAudioData` 解码一次后复用
- 播放窗口上限 1.15s，尾部 60ms 指数淡出；解码失败则退回实时合成的木击音

换音色：替换 `assets/knock.mp3` → 重新编码进 `client.js` 的 `KNOCK_B64` → 刷新页面。

## 配置

设置 → 下班倒计时：

| 字段 | 说明 |
| --- | --- |
| 上班时间 / 下班时间 | `HH:MM`（24 小时制） |
| 工作日 | `0`=周日 … `6`=周六，支持 `1,2,3,4,5` 或 `1-5` |
| 显示秒 | 关闭后只显示到分钟 |
| 悬浮胶囊 | 离开头部，变成可拖动浮窗 |
| 天气城市 | 中文城市名，如 `杭州`；留空则不显示天气 |
| 显示天气 | 关掉后胶囊与面板都不显示天气 |
| 显示用量 | 关掉后胶囊与面板都不显示 OCG 用量环 |
| 音量 | 0~100 滑杆，控制敲木鱼的声音；0 = 静音（只保留弹跳动画） |

写入走 `settings.update(ns, patch, revision)`，落到当前 profile 的 Cordis 补丁层。时间非法（下班早于上班）时保存会被拦下。

## 天气数据

宿主侧拉取（`open-meteo`，免费无 Key），每 15 分钟一次，写成 volatile 快照，客户端只读投影：

- 城市名 → 经纬度（地理编码结果缓存 24 小时）
- 拉取内容：当前气温/体感/天气码 + 逐小时 + 逐日
- **失败保留上一次成功快照**，并在面板底部提示「天气更新失败，显示的是上次结果」；从不让天气拖累倒计时
- 快照没变就不写回，避免每轮刷新都刷一遍配置

## OpenCode Go 用量

宿主直连 `https://opencode.ai/zen/go/v1/usage`（自己拉，不去读另一个插件的配置）：

- Key 来源：`ctx.inject(['credentials'])` **等待凭据服务就绪**（不是点查后判空），再按 `OPENCODE_GO_API_KEY` → `OPENCODE_API_KEY` 取；服务未就绪时写 `keyStatus: loading` 并按 1/2/4/8/15/30 秒快速重试，**启动后几秒内就出数**（此前是干等 60 秒定时器）
- 解析：接口给的 `percent`（已用）优先；也兼容 `remainingPercent`（反算）、`used/limit`（折算）；取值夹到 0~100 取整
- 刷新间隔默认 5 分钟，随 `usageRefreshMinutes`（1~60）调整
- 失败保留上一次成功快照，只写 `usage.error`；从未成功过就不出环
- 面板提示分三态：`正在获取用量…`（还没就绪）/ 错误原文（请求失败）/ `未配置 OpenCode Go Key`（确实没配）
- 401 / 403 会点名（Key 失效 / 无订阅），方便排查

## 结构与取舍

- `index.js`（宿主）：Config 声明 + 天气拉取 + 快照写回。
- `client.js`（浏览器）：三个席位（头部 / 浮层 / 设置页）+ 胶囊 + 详情面板；样式只用 `--dsw-alias-*` 主题令牌。
- `cordis.patch.yml`：插入一行 Loader 条目，id `work-countdown` 同时是配置命名空间。
- `test/offline-render.mjs`：假环境渲染断言 + 拖动实现的结构守卫。

浮窗定位记的是**锚边 + 到锚边的距离**，不是绝对坐标；拖动只改 `transform`，松手后位移保持到配置写回那一刻才换成新锚边，中途不会跳。顶部锚会自动加上桌面版标题栏高度（win32 = 40px），不会落进窗口按钮带。

取舍：浮层不参与布局，勾选浮窗后它会浮在任何内容之上——包括右侧文件栏、终端抽屉和设置弹窗。这是浮窗的本意，盖住了拖开即可。
