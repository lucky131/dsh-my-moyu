# my Moyu（dsh-my-moyu）

自用上班摸鱼助手：下班倒计时、天气、OCG 用量、今日黄历、六十四卦、塔罗、电子木鱼、键盘农场、便笺、颜色转换、时间戳转换。

除天气与用量外，所有功能都完全离线：数据内嵌、随机源用 `crypto.getRandomValues`、不联网、不上传。

## 下班倒计时

按配置的上班 / 下班时间算距离下班还有多久，工作日之外显示「休息日」，下班后显示「已下班」。

- 可配置上班时间、下班时间、工作日、是否显示秒
- 时间非法（下班早于上班）时保存会被拦下

## 天气

宿主侧拉取 [open-meteo](https://open-meteo.com/)（免费、无需 Key），每 15 分钟一次，客户端只读快照。

- 内容：当前气温 / 体感 / 天气码，未来 24 小时逐时，未来 3 天
- 城市名 → 经纬度，地理编码结果缓存 24 小时
- 直连与本地代理**并发请求**，谁先返回用谁，另一条立刻中断；超时是配置项 `requestTimeoutSeconds`（默认 30 秒，范围 5~120）
- 失败保留上一次成功快照，只提示失败原因，不拖累倒计时；快照没变就不写回配置
- 手动刷新：点刷新按钮写 `ping`，宿主立刻补刷

## OCG 用量

宿主直连 `https://opencode.ai/zen/go/v1/usage` 自己拉取，不依赖其他插件。

- 三个窗口：5 小时 / 本周 / 本月，显示已用百分比与重置时刻
- Key 来源：注入凭据服务后按 `OPENCODE_GO_API_KEY` → `OPENCODE_API_KEY` 取；未就绪时按 1/2/4/8/15/30 秒重试
- 解析 `percent`，兼容 `remainingPercent`、`used/limit`；取值夹到 0~100
- 刷新间隔默认 5 分钟，可配 1~60 分钟；401/403 会点名 Key 失效或无订阅

## 今日黄历

公历日期、农历、干支、值神（黄道/黑道）、宜、忌、冲煞、建除、二十八宿。

- 计算在宿主侧完成，纯本地、不联网；每天算一次，日期变了才重写
- 算法：干支日柱 + 建除十二神 + 二十八宿 + 黄黑道十二神 + 神煞叠加，按「以凶制吉 / 宜忌从多」汇总，规则集大成于《协纪辨方书》
- 宜忌条数属流派差异，不是 bug
- 依赖 `lunar-typescript`（MIT），内联在 `vendor/lunar.cjs`

## 六爻

点签筒起一卦，给卦序、卦名、六爻图、卦辞原文与白话总述；有动爻时并排给出变卦。

- 铜钱法：三枚铜钱摇六次，每爻 1/8 老阴、3/8 少阴、3/8 少阳、1/8 老阳；老阴/老阳为动爻，翻转得变卦
- 只有卦辞，没有 384 条爻辞；动爻只标位置
- 一次一卦，不入库、不记录、关掉即弃

## 塔罗

从 22 张大阿卡那里连抽 3 张（不重复），每张独立随机正 / 逆位，按「过去 · 现在 · 未来」落位。

- 每张给位置专属解读，底部按逆位张数给一段综合判断
- 位置专属解读共 132 段（22 张 × 3 位置 × 正逆），另有 44 段单张牌义兜底

## 木鱼

点一下播一次敲击音并弹跳，点击次数不计入键盘统计。

- 音源：Temple block - Lunarlander 1969 by Sadiquecat（freesound.org/people/Sadiquecat/sounds/742279/），CC0 1.0
- `assets/knock.mp3` 与内联进 `client.js` 的 base64 副本内容必须一致；解码失败时退回实时合成音
- 音量可配 0~100，0 = 只留动画

## 键盘农场

把按键次数变成一块块田：每个键对应一格土地，作物随按键次数长大，满级可收获。

- 只统计 DSH 窗口内的按键（`document` 上的 `keydown`，按 `event.code`），过滤长按重复
- 六个生长档：0 / <10 / <50 / <200 / <1000 次，满 1000 成熟，发光提示
- 作物种类与姿态（翻转、偏移、摇摆幅度）在**该格第一次被计数时**随机定型，之后不再变
- 满级点击收获，作物进库存；未满级点击直接 **次数 +1**
- 库存按作物种类统计，显示在键盘浮窗底部
- 数据存配置的 `keyStats` / `keyCrops` / `cropStock`，停手 5 秒或页面隐藏时写回；只记「哪个键按了几次」，不记序列
- 设置页可「清空数据」（二次确认），一并清掉统计、外观与库存
- 曾尝试 `WH_KEYBOARD_LL` 全局钩子统计整个 Windows，实测这台机器上低级钩子与 `GetAsyncKeyState` 轮询全部收不到事件，已放弃并移除

## 便笺

每点一次新建一张便笺，可自由输入、拖动、办完删除。

- 高度随内容自动增长，不出现内部滚动条
- 位置随便笺保存，内容与坐标存 `notes` 字段，输入停 500ms 或页面隐藏时写回

## 颜色转换

粘 QQ 截图吸色复制出来的 `65,118,230`（全角逗号、空格都认），实时给出 `rgb(...)` 与 `#hex`，各自可一键复制。

- 输入框右侧有色块预览；格式不对给红字提示；上次输入会记住

## 时间戳转换

输入秒或毫秒时间戳，输出本地时区的 `2026-01-01 11:11:11`，并标明按秒还是按毫秒解析。

- 判据是数值 `1e11`：秒到 2286 年才 11 位，毫秒 1973 年起就是 13 位
- 只认纯数字，不做兜底猜测

## 配置

设置 → 下班倒计时：

| 字段 | 说明 |
| --- | --- |
| 上班时间 / 下班时间 | `HH:MM`（24 小时制） |
| 工作日 | `0`=周日 … `6`=周六，支持 `1,2,3,4,5` 或 `1-5` |
| 显示秒 | 关闭后只显示到分钟 |
| 悬浮胶囊 | 离开头部，变成可拖动浮窗 |
| 天气城市 | 中文城市名，如 `杭州`；留空则不显示天气 |
| 显示天气 | 关掉后不显示天气 |
| 显示用量 | 关掉后不显示 OCG 用量 |
| 请求超时 | 直连与代理都超过这个时间才算失败，默认 30 秒 |
| 音量 | 0~100 滑杆，0 = 静音（只保留动画） |

写入走 `settings.update(ns, patch, revision)`，落到当前 profile 的 Cordis 补丁层。

## 结构

- `index.js`（宿主）：Config 声明 + 天气 / 用量拉取 + 快照写回
- `client.js`（浏览器）：界面与全部离线功能
- `vendor/lunar.cjs`：内联的农历库（本插件用 `link:` 安装，裸包名解析不到 profile 的 `node_modules`）
- `test/offline-render.mjs`：假环境渲染断言 + 结构守卫
